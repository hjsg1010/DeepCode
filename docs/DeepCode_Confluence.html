DeepCode 개요

DeepCode는 HKU Data Intelligence Lab에서 개발한 Multi-Agent 기반 코드 자동 생성 시스템임. 연구 논문(PDF)이나 자연어 요구사항을 분석하여 실제 작동하는 production-ready 코드를 자동 생성함.

주요 특징

특징 설명
BlueMulti-Agent 전문화된 Agent들의 협업을 통한 고품질 코드 생성
GreenMCP 기반 Model Context Protocol을 통한 모듈화된 도구 시스템
Yellow다중 입력 PDF, URL, 텍스트, PPTX, DOCX 등 다양한 입력 지원
Purple다중 인터페이스 CLI 및 Web UI (Streamlit) 동시 지원
RedCodeRAG Knowledge Graph 기반 코드 인덱싱 및 참조 시스템

핵심 기능

Paper2Code

연구 논문(PDF)에서 알고리즘을 추출하여 production-ready 코드로 자동 변환. 학술 논문 재현 작업 자동화.

Text2Web

자연어 설명을 기반으로 fully functional frontend 웹 코드 생성. React, Vue 등 다양한 프레임워크 지원.

Text2Backend

텍스트 요구사항으로부터 scalable backend 코드 생성. FastAPI, Flask, Express 등 지원.

MCP Tool Servers

MCP (Model Context Protocol): AI Agent와 외부 시스템 간 통신을 위한 표준 프로토콜. DeepCode는 MCP를 통해 다양한 도구를 모듈화하여 통합함.

도구 서버 목록

MCP Server 기능 주요 Tool
filesystem 파일 시스템 접근 read_file, list_directory
code-implementation 파일 생성 및 코드 실행 write_file, execute_python, execute_bash
document-segmentation 대용량 문서 지능형 분할 analyze_document, get_segment
code-reference-indexer 코드 인덱스 검색 search_code_references, get_indexes_overview
file-downloader PDF/문서 다운로드 및 변환 download_file
github-downloader Git Repository 클론 clone_repository
brave / bocha-mcp 웹 검색 brave_search, web_search
command-executor 시스템 명령어 실행 execute_command

Code Indexing (CodeRAG)

CodeRAG는 참조 코드베이스를 LLM 기반으로 분석하여 Knowledge Graph 인덱스를 생성함. 코드 생성 시 관련 코드 패턴, 함수, 개념을 검색하여 참조 가능.

인덱싱 프로세스

text LLM Indexing Pipeline 0.3 파일 선별 Step 3: File Analysis (파일별 반복) └─ "이 파일의 함수, 개념, 의존성은?" → 구조화된 파일 요약 생성 Step 4: Relationship Analysis (파일별 반복) └─ "이 파일이 target의 어떤 파일 구현에 도움이 될까?" → 관계 매핑]]>
